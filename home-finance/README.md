# 🏠 Home Finance Manager

A complete personal/home expense management web app that runs entirely in your browser. No server needed!

## Features
- ✅ Add Income & Expenses with full details
- 📝 Notes, Date/Time, Category, Payment Method
- 👥 Track People & Pending Payments (who you owe / who owes you)
- 📊 Dashboard with Charts & Stats
- 📈 Detailed Reports & Analytics
- 🔍 Search, Filter & Sort Transactions
- ✏️ Edit & Delete Transactions
- 📤 Export Data (JSON & CSV)
- 📥 Import Data (JSON)
- 🌙 Dark/Light Theme
- 💱 Multi-Currency Support
- 📱 Fully Responsive (Mobile Friendly)
- 💾 All data stored locally (localStorage)

## Deploy on GitHub Pages

1. Create a new repository on GitHub
2. Upload all files maintaining folder structure
3. Go to Settings → Pages → Source: main branch → Save
4. Your site will be live at: https://yourusername.github.io/repo-name/

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- Chart.js (CDN) for charts
- Google Fonts (Inter)
- localStorage for data persistence

## ⚠️ Important
- Data is stored in your browser's localStorage
- Export data regularly as backup
- Clearing browser data will delete all records
